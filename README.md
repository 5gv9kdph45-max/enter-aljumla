# سنتر الجملة — تطبيق Flutter (نسخة تجريبية)

تطبيق موبايل أصلي قابل للبناء للأندرويد والآيفون. واجهة عربية RTL، منتجات تجريبية، بحث وتصنيفات، سلة مشتريات، طلبات تجريبية محلية، واختيار طريقة الدفع.

## التشغيل
1. ثبّت Flutter SDK على كمبيوتر (Mac مطلوب لبناء iOS).
2. افتح Terminal داخل هذا المجلد وشغّل:
   `flutter create --platforms=android,ios .`
3. شغّل `flutter pub get`
4. شغّل `flutter run` مع هاتف أو محاكي متصل.
5. للأندرويد: `flutter build apk --release`
6. للآيفون: افتح `ios/Runner.xcworkspace` باستخدام Xcode على Mac واضبط توقيع التطبيق.

## تنبيه
هذه نسخة أولية للعرض فقط. الطلبات لا تصل إلى المتجر ولا تُخزَّن على خادم؛ تختفي بعد إغلاق التطبيق. الدفع الإلكتروني غير مفعّل. الأسعار والمنتجات تجريبية. تطبيق الإدارة المنفصل، قاعدة البيانات، توثيق الهاتف، إدارة المخزون، والإشعارات تحتاج مرحلة تطوير وربط خادم آمن.

لا تضع مفاتيح API أو أسرار الدفع داخل ملفات Flutter أو مستودع عام.
